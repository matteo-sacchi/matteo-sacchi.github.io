# Matteo Sacchi — Academic website

A lightweight static academic website built with plain HTML, CSS and a tiny amount of JavaScript.

## Files

- `index.html` — the whole website
- `styles.css` — styling and responsive layout
- `script.js` — light/dark theme toggle
- `Matteo_Sacchi_CV.pdf` — downloadable CV
- `matteo-sacchi.jpg` — portrait used on the homepage

## Publish with GitHub Pages

1. Create a GitHub repository named `matteosacchi.github.io`.
2. Upload all the files in this folder to the root of the repository.
3. Commit them to the `main` branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
5. The site will be available at `https://matteosacchi.github.io/`.

If your GitHub username is different, either name the repository `<username>.github.io`
or keep another repository name and publish it as a project page.

## Easy edits

The site is intentionally dependency-free. You can edit `index.html` directly:
- research text is in the `#research` section;
- publications are in `#publications`;
- talks are in `#talks`;
- contact information is in `#contact`.

The design automatically adapts to phones and to the visitor's system light/dark theme.
